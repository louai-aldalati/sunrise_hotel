# AI Hotel Chatbot

An intelligent customer support assistant designed for hotels using modern **Large Language Model (LLM)** technology.  
This project builds a domain-specific chatbot that can answer guest questions automatically based on hotel policies, services, and internal knowledge.

## Overview

The system is built using **Llama 3 (8B Instruct)** and enhanced with **Retrieval-Augmented Generation (RAG)** and **Fine-Tuning** techniques to provide accurate and context-aware responses.  
It allows hotels to automate customer support while ensuring answers remain aligned with their specific policies and services.

## Key Features

- AI-powered chatbot for hotel customer support
- Customized responses based on hotel policies and documentation
- Retrieval-Augmented Generation (RAG) for knowledge-based answers
- Fine-tuning to adapt the model to a specific hotel environment
- Natural language understanding for guest inquiries

## Technologies Used

- Llama 3 (8B Instruct)
- Retrieval-Augmented Generation (RAG)
- Fine-Tuning
- Natural Language Processing (NLP)
- Python
- Hugging Face
- Unsloth (for efficient LLM training)

## Project Structure

The project includes:

- Dataset preparation based on hotel policies
- Model loading and configuration
- Fine-tuning the language model
- Knowledge retrieval integration
- Chatbot response generation

## Goal

The goal of this project is to demonstrate how open-source LLMs can be adapted for **real-world business applications**, enabling hotels to provide faster and more efficient customer support through AI.
